Ferramenta de automação de código aberto para a alocação do **Abstract Chain Genesis**. Este script permite verificar a elegibilidade, analisar a atividade da carteira e reivindicar recompensas de forma segura usando um ambiente local Python.

---

## ✨ Funcionalidades
* **Auto-Claim:** Reivindica tokens automaticamente para todos os níveis elegíveis.
* **Otimizador de Gas:** Calcula as taxas de gas mais baixas para economizar ETH.
* **Segurança de Snapshot:** Verifica o histórico da carteira para garantir a conformidade com a snapshot.

---

## ❌ Erros Comuns e Soluções

Se você receber erros como `Error: 0x434` ou `Python path not found`, isso significa que seu ambiente local não está configurado corretamente ou que faltam certificados SSL essenciais no seu sistema.
